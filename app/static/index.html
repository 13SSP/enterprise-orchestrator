How to Onboard a New Agent to Enterprise Orchestrator

The platform supports four standardized pathways for teams to deploy and register agents into the Gemini Orchestrator Router.

1 Low-Code Swagger / OpenAPI Auto-Generation (Fastest)

Provide any OpenAPI 3.0 or Swagger 2.0 YAML or JSON specification. The engine automatically parses endpoints into ADK tools, synthesizes a semantic description and system prompt, and binds them to the new agent.

  • Paste the spec in the "From Swagger / OpenAPI" tab.
  • Configure Role Limits (`allowed_roles`) and Team Limits.
  • Click Generate Agent & Register Tools. The agent is immediately active in the router!

2 Manifest-Driven Registration

For existing sub-agents or custom agents without OpenAPI definitions, register an AgentManifest via the UI form or POST /api/agents/onboard.

3 Native ADK Code Sub-Agent (Python Package)

For deep reasoning agents with custom Python workflows, implement a sub-agent package under agents/<agent-name>/.

4 Remote Microservice via Agent-to-Agent (A2A) Protocol

Deploy an external microservice on Cloud Run or Kubernetes implementing the A2A spec, then register its URL as agent_type: "remote_a2a".

✓ Post-Onboarding Verification Checklist

1. Verify your agent card appears under "All" and "Your agents".

2. Prompt the AI Chat to verify semantic routing directs queries to the new agent.

3. Switch identity to test role access enforcement and human write confirmation.
